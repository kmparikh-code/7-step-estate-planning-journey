# Mossy Creek Wealth — Estate Planning Journey

An interactive, seven-step estate-planning guide for Mossy Creek Wealth clients. The page features a realistic desk with clickable step labels, readable detail panels, and an expanded funding checklist with a prominent funding callout.

## Run

Open `index.html` in a browser. No installation or build step is required. Keep the included images alongside the HTML file.

## Edit content

In `index.html`, find the JavaScript array beneath `SEVEN STEPS: EDIT ALL WORDING AND OPTIONAL LINKS IN THIS ARRAY.` Each step includes its label, description, advisor tasks, client tasks, and optional link. Step 4 also includes the funding callout heading and text. A link button remains hidden until its URL is supplied.

## GitHub Pages

The site is ready to serve from the `main` branch at the repository root. Publishing is separate from saving this repository. GitHub Pages eligibility depends on the account plan and repository visibility.

## Included files

`index.html` contains the page styling, scripts, embedded fonts, and font-license metadata. The JPEG, WebP, and transparent PNG files are the page's image assets. `.nojekyll` tells GitHub Pages to serve the files without Jekyll processing.

The page does not collect or submit client information. Brand assets and page content are not licensed for general reuse by this repository.
